Getting Started

When you first open the Idea Board, you'll be asked to enter your name. This identifies you across the team — your name appears on ideas you submit, comments you post, and votes you cast.

A guided tour will automatically walk you through the main features on your first visit. You can replay it anytime by clicking the Tour button in the top-right corner.

Tip: Use your full name so team members know who submitted each idea.

Adding Ideas

Click the + New Idea button in the toolbar to submit an idea.

Fields:

FieldRequiredDescription
TitleYesA short, clear name for your idea
DescriptionNoDetailed explanation of what the idea involves
BenefitsNoWhat value does this bring? Time saved, cost reduced, quality improved?
CategoryYesProcess Improvement, Technology, Customer Experience, Cost Saving, Team Culture, or Other
PriorityYesHigh, Medium, or Low
StatusYesNew, In Progress, Review, or Done (defaults to New)
Submitted ByAutoAuto-fills with your name

Board View & List View

Board View (Kanban)

Ideas are displayed as cards in four columns: New → In Progress → Review → Done. Each card shows the title, category, priority, benefits preview, submitter, and vote count.

List View (Table)

Ideas displayed in a sortable table with columns for Title, Category, Status, Priority, Votes, Submitted By, Date, and Last Change. Click any column header to sort ascending/descending.

Drag and Drop

In Board view, grab any card and drag it:

  • Between columns — changes the idea's status (e.g., drag from New to In Progress)
  • Within a column — reorders cards (a blue line shows where it will land)

Status changes via drag are recorded in the audit log with timestamps.

Voting

Each idea has upvote (▲) and downvote (▼) buttons. Click to vote — click again to remove your vote. One vote per person per idea.

  • Green score = positive consensus
  • Red score = negative consensus
  • In List view, you can sort by votes to see the most popular ideas

Comments

Click any idea to open its detail view. Scroll to the bottom to see the comments thread. Type your comment and click Post.

  • You can delete your own comments (x button)
  • Comment count shows on the card (speech bubble icon)
  • Comments are included in the audit log

Dashboard Stats

The stats bar above the toolbar shows at-a-glance metrics:

  • Total Ideas — all ideas in the system
  • New / In Progress / Review / Done — count by status
  • This Month — ideas created in the current month
  • Top Contributor — person who submitted the most ideas

Interactive filtering:

  • Hover over a stat card — the board/list dims non-matching items instantly
  • Click a stat card — locks the filter (click again or click outside to clear)
  • In List view, non-matching rows are hidden (true filter)
  • In Board view, non-matching cards fade out, matching column highlights

Search & Filtering

Use the toolbar controls:

  • Search box — searches title, description, benefits, and submitter name
  • Category dropdown — filter to a specific category
  • Priority dropdown — filter by High/Medium/Low

All filters work together (additive). Clear them to see all ideas.

Bulk Actions

In List view, each row has a checkbox. Select multiple ideas to reveal the bulk action bar:

  • Change Status — move all selected to a new status
  • Change Priority — set all to High/Medium/Low
  • Change Category — reassign category
  • Delete — removes ideas you have permission to delete
  • Select All — checkbox in header selects all visible (filtered) rows
Note: Contributors can only bulk-delete their own ideas. The delete button shows how many of your selection you can delete.

Dark Mode

Click the moon/sun icon (🌙 / ☀️) in the header to toggle between light and dark themes. Your preference is saved and persists across sessions.

Roles & Permissions

RoleCan Do
AdminEverything — edit/delete any idea, manage categories, manage users, import/export, manage data
ContributorAdd ideas, edit/delete own ideas, comment, vote, change status (drag), bulk actions on own ideas

You are a Contributor by default. The team admin (Isaac Gera) can promote you to Admin if needed.

Admin Features

Admin-only features accessible via the Manage Data button:

  • Export — Download all ideas as JSON + copy summary to clipboard
  • Import — Load ideas from a JSON file (merges with existing)
  • Categories — Add/remove categories
  • Manage Users — Promote/demote, rename, or delete users
Tip: When you delete a user, their ideas are automatically reassigned to the admin.

Export & Import

Export (admin only): Downloads a JSON file of all ideas and copies a readable text summary to your clipboard — great for sharing via email or Teams.

Import (admin only): Load ideas from a JSON file. Supports both array format and object format. Ideas are merged (not replaced).

Tips & Best Practices

  • Write clear, actionable titles (e.g., "Automate weekly report generation" not "Reports")
  • Always fill in the Benefits field — it helps the team prioritise
  • Use voting to surface the ideas with the most team support
  • Move ideas through the workflow: New → In Progress → Review → Done
  • Comment on ideas to add context, ask questions, or show support
  • Use the dashboard filters in team meetings to focus discussion
  • Review "stale" ideas (stuck in New for weeks) regularly
  • Export periodically as a backup of your team's ideas
Need help? Click the Tour button in the app header for a guided walkthrough, or contact your admin (Isaac Gera).

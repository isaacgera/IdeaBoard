Getting Started

When you first open the Idea Board, you'll be asked to enter your full name. This is mandatory — the app will not proceed until a valid name is entered. Your name identifies you across the team for ideas, comments, and votes.

A guided tour will automatically walk you through the main features on your first visit. You can replay it anytime by clicking the Tour button in the top-right corner.

Tip: Use your full name so team members know who submitted each idea. Your name cannot be changed later (only admin can rename users).

Adding Ideas

Click the + New Idea button in the toolbar to submit a new idea.

Fields:

FieldRequiredDescription
TitleYesA short, clear name for your idea
DescriptionNoDetailed explanation of what the idea involves
BenefitsNoWhat value does this bring? Time saved, cost reduced, quality improved?
CategoryYesProcess Improvement, Technology, Customer Experience, Cost Saving, Team Culture, or Other
PriorityYesHigh, Medium, or Low
StatusYesNew, In Progress, Review, or Done (defaults to New)
Submitted ByAutoAuto-fills with your name
Tip: Always fill in the Benefits field — it helps the team understand the value and prioritise effectively.

Board View & List View

Board View (Kanban)

Ideas are displayed as cards in four columns: New → In Progress → Review → Done. Each card shows the title, category, priority badge, benefits preview, submitter, comment count, and vote score.

List View (Table)

Ideas displayed in a sortable table with columns: checkbox, Title, Category, Status, Priority, Votes, Submitted By, Date, and Last Change.

  • Click any column header to sort ascending/descending
  • Arrow indicators show current sort direction
  • Priority sorts by weight (High → Medium → Low)
  • Status sorts by workflow order (New → In Progress → Review → Done)

Drag and Drop

In Board view, grab any card and drag it:

  • Between columns — changes the idea's status (e.g., drag from New to In Progress)
  • Within a column — reorders cards by priority/importance
  • A blue indicator line shows exactly where the card will land
  • The target column highlights with a dashed border while hovering

Status changes via drag are automatically recorded in the audit log with timestamp and your name.

Tip: Clicking a card opens its detail view. Dragging a card moves it. The app distinguishes between clicks and drags automatically.

Voting

Each idea has upvote (▲) and downvote (▼) buttons visible on every card and in the detail view.

  • Click ▲ to upvote, click again to remove your vote
  • Click ▼ to downvote, click again to remove
  • One vote per person per idea (you can't upvote AND downvote)
  • Green score = positive consensus, Red score = negative
  • In List view, sort by the "Votes" column to see most popular ideas

Comments

Click any idea card to open its detail view. At the bottom you'll find the comments thread.

  • Type your comment in the text area and click Post
  • Comments show your name, timestamp, and the text
  • You can delete your own comments (x button next to your comments)
  • Comment count appears on each card (💬 icon)
  • Adding/deleting comments is logged in the audit trail

Interactive Filtering:

  • Hover over a stat card — non-matching items dim/hide instantly (preview)
  • Click a stat card — locks the filter (stays active until you click elsewhere)
  • Click outside the dashboard — clears the filter, shows all items
  • Click "Total Ideas" — explicitly clears any active filter

In Board view, non-matching cards fade to near-invisible. In List view, non-matching rows are completely hidden (true filter).

Search & Filtering

Use the toolbar controls to narrow down ideas:

  • Search box — live search across title, description, benefits, and submitter name
  • Category dropdown — filter to a specific category
  • Priority dropdown — filter by High, Medium, or Low

All filters combine (e.g., search "automation" + category "Technology" + priority "High" shows only matching ideas). Clear all to see everything.

Bulk Actions

In List view, each row has a checkbox on the left. Select one or more ideas to reveal the bulk action bar (purple bar above the table):

  • Select All — header checkbox selects all visible (filtered) rows
  • Change Status — move all selected to New/In Progress/Review/Done
  • Change Priority — set all selected to High/Medium/Low
  • Change Category — reassign category for all selected
  • Delete — removes ideas you have permission to delete
  • Clear — deselects all items
Permission note: Contributors can only bulk-delete their own ideas. If you select a mix of own + others' ideas, the delete button shows "Delete 2 of 5 (yours)" indicating only your ideas will be removed.

Dark Mode

Click the moon/sun icon (🌙 / ☀️) in the top-right header area to toggle between light and dark themes.

  • Your preference is saved and persists across browser sessions
  • All UI elements adapt including cards, modals, forms, and the dashboard

Admin Features

Admin-only features accessible via the Manage Data button in the toolbar:

Export & Import

  • Export as JSON — downloads all ideas as a JSON file + copies a readable text summary to your clipboard
  • Import from JSON — merge ideas from a previously exported file

Category Management

  • View all categories with remove buttons
  • Add new categories via text input
  • Categories sync across all users in real-time

User Management (Manage Users & Roles)

  • Promote — elevate a contributor to admin
  • Demote — reduce an admin back to contributor
  • Edit (Rename) — changes the user's name; all their ideas, comments, and history entries are remapped to the new name
  • Delete — removes the user; all their ideas are reassigned to you (admin)
Note: The hardcoded admin (Isaac Gera) cannot be demoted or deleted.

Online Users

The green badge in the header (e.g., "3 online") is visible to admin only. Click it to see a list of team members currently active on the board, with green status indicators.

Export & Import

Export (admin only):

  • Downloads a JSON file with all idea data (including votes, comments, history)
  • Simultaneously copies a human-readable text summary to your clipboard
  • Great for sharing via email, Teams, or as a backup

Import (admin only):

  • Accepts JSON files in array format or object format
  • Merges with existing ideas (doesn't overwrite)
  • Also imports categories if present in the file
  • Infers milestone dates from status for ideas without date data

Audit Log & Timeline

Every idea has a complete audit trail visible in its detail view:

Timeline

A visual bar showing four milestones with dates:

  • Created — when the idea was first submitted
  • Started — when status first changed to "In Progress"
  • In Review — when status first changed to "Review"
  • Completed — when status first changed to "Done"

Active milestones are highlighted in purple with their timestamp.

Version History

A scrollable log showing every change to the idea:

  • Creation events
  • Status changes (with from → to)
  • Field edits (title, description, benefits, category, priority)
  • Comments added
  • Bulk action changes (marked with "(bulk)")
  • User reassignments (when a user is renamed/deleted)

In List view, the "Last Change" column shows the most recent audit entry for quick reference.

Tips & Best Practices

  • Write clear, actionable titles (e.g., "Automate weekly report generation" not "Reports")
  • Always fill in the Benefits field — it helps the team prioritise
  • Use voting to surface the ideas with the most team support
  • Move ideas through the workflow: New → In Progress → Review → Done
  • Comment on ideas to add context, ask questions, or show support
  • Use the dashboard stat cards in team meetings to focus discussion
  • Review "stale" ideas (stuck in New for weeks) regularly
  • Use bulk actions during review meetings to triage multiple ideas at once
  • Export periodically as a backup of your team's ideas
  • Try dark mode for comfortable evening/low-light usage
